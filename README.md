# McPay Moçambique 
Sistema de pagamentos aprovado Banco de Moçambique

## Fluxos
- USSD *258#
- QR Fixo Agente MCP023
- P2P @username
- Pagamento Shop MC

## Rodar no GitHub Codespace (sem PC)
1. Code > Codespaces > Create
2. pip install -r requirements.txt
3. python app.py
4. docker-compose up -d (para banco)
